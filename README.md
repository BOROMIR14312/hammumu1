# 🔨 HAMMUMU

**Bonk the noobs. Spare the pros. 30 seconds.**

A zero-dependency whack-a-mole built in one HTML file. No build step, no frameworks, no mercy.

## How to play

Open `index.html` in a browser. That's it.

- 😵 **Noobs** (orange) pop out of holes — smash them. **+10**
- 😎 **Pros** (green, sunglasses) pop out too — do NOT smash the pros. **−15**
- Chain noob-bonks for a 🔥 **combo bonus** (up to +10 extra per hit)
- It gets faster. You will panic. This is intended.
